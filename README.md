# Україна · карта тривог і цілей NEPTUN

Ветка `all-ukraine`: карта всей Украины с тревогами по 136 районам, отдельными статусами Киева и Севастополя, границами 27 регионов и публичными целями NEPTUN. Включены Крым и временно оккупированные территории. По умолчанию открывается только карта; кнопка «Показати панелі» открывает списки и выбор области. Подходит для iframe.

## Portainer

В существующем Stack → Editor укажите:

```yaml
image: ghcr.io/kerber0ss/sumy-alarm-map:all-ukraine-neptun
```

Нажмите **Update the stack** с включённым **Re-pull image**. Перезапуск контейнера сам по себе не загружает новый образ.

При создании Stack через Git укажите repository `https://github.com/Kerber0ss/sumy-alarm-map`, reference `refs/heads/all-ukraine`, compose path `compose.yaml`. В этой ветке Compose уже использует тег `all-ukraine-neptun`.

Полный Stack и дополнительные настройки: [PORTAINER.md](PORTAINER.md).

## Docker Compose

```sh
git clone --branch all-ukraine https://github.com/Kerber0ss/sumy-alarm-map.git
cd sumy-alarm-map
docker compose pull
docker compose up -d
```

Адрес: `http://SERVER_IP:8765`. Образ поддерживает Linux amd64 и arm64, работает от UID 65532 с read-only filesystem. База данных и API-ключи не нужны.

Пуш в `all-ukraine` запускает проверки, сборку и публикацию `ghcr.io/kerber0ss/sumy-alarm-map:all-ukraine-neptun` и `:sha-<полный commit SHA>`. Теги `latest` и `neptun` закреплены за соответствующими ветками `main` и `neptun`; новый тег их не перезаписывает.

## Данные и отображение

- Сервер получает тревоги через `https://neptun.in.ua/api/v1/alerts`, цели через `/api/v1/threats`, кеширует и обновляет их раз в 10 секунд. Тревоги — официальные статусы в API NEPTUN. WebSocket и дополнительные Python-пакеты не используются.
- Областная тревога наследуется районами своей области. Красный уровень приоритетнее жёлтого, оба уровня остаются в деталях. Неизвестные уровни и ошибки источника отображаются как отсутствие подтверждённых данных, а не отбой. API предоставляет районы и области; отдельные тревоги громад в этой версии не отображаются.
- Все публичные цели источника сохраняются, включая подходы у границ. Отображаются курс, описание, размер группы, достоверность, число источников, время обновления, скорость и погрешность позиции при наличии. Курс неизвестен — стрелка направления в карточке отсутствует. Дополнительная экстраполяция положения не выполняется.
- Сообщения `areaOnly` показываются в списке без точечного маркера и курса; нажатие открывает соответствующую область. Выбор территории фильтрует списки и маркеры и приближает область. «Вся Україна» в верхней части карты возвращает общий обзор.
- Ошибка запроса или истечение свежести скрывает цели; недоступные тревоги показываются серым. Ссылки NEPTUN и OpenStreetMap видны в том числе в режиме карты без панелей.
- Границы районов и областей поставляются локально в `public/ukraine.geojson`, получены из публичных GeoJSON, указанных в документации NEPTUN. Идентификаторы совпадают с API; привязка районов к областям рассчитана по геометрии. [Источники и права](THIRD_PARTY.md).

NEPTUN — информационный агрегатор, данные могут задерживаться и содержать неточности. Отсутствие целей не означает безопасность. Ориентируйтесь на официальные сигналы воздушной тревоги.

## Локально и проверка

Python 3.10+:

```sh
python3 server.py
```

Адрес: `http://127.0.0.1:8765`. Параметры: `--host 0.0.0.0`, `--port 8766`.

```sh
python3 -m unittest -v test_server.py
node --check public/app.js
node test_app.js
docker compose config --quiet
docker build -t all-ukraine-neptun:local .
```

Сервер отдаёт только `public/` и `/api/state`; исходники и служебные файлы через HTTP недоступны.
