# Сумщина · карта тривог

Карта Сумской области: уровни воздушной тревоги по пяти районам, публичные отметки целей и курс из источника. По умолчанию только карта и кнопка «Показати панелі»; подходит для iframe. Конотопский район закреплён первым, список целей находится над районами.

## Запуск готового образа

```sh
git clone https://github.com/Kerber0ss/sumy-alarm-map.git
cd sumy-alarm-map
docker compose pull
docker compose up -d
```

Открыть **http://SERVER_IP:8765**. Порт по умолчанию опубликован на всех интерфейсах. API-ключи, Docker Hub и отдельная база данных не нужны.

Образ: **`ghcr.io/kerber0ss/sumy-alarm-map:latest`**, Linux `amd64` и `arm64`. GitHub Actions проверяет приложение и контейнер перед публикацией; после каждого push в `main` обновляет `latest` и добавляет тег `sha-<полный commit SHA>`.

Ветка `neptun` автоматически публикует отдельный образ `ghcr.io/kerber0ss/sumy-alarm-map:neptun` (amd64 и arm64). Для его использования замените `:latest` на `:neptun` в `compose.yaml`, затем выполните `docker compose pull && docker compose up -d`. Тег `latest` публикуется только из `main`; ручной запуск разрешён для `main` и `neptun` с теми же тегами.

## Локально без Docker

Python 3.10+, без дополнительных Python-пакетов:

```sh
python3 server.py
```

Адрес http://127.0.0.1:8765, остановка Ctrl+C. Параметры: `--port 8766`, `--host 0.0.0.0` для доступа с других устройств. Без `--host` сервер слушает только loopback.

Локальная сборка контейнера вместо загрузки готового образа:

```sh
docker compose -f compose.yaml -f compose.build.yaml up -d --build
```

## Как работает

- Тревоги: публичный HTTP `/api/v2/data/mapUpdate` на map.ukrainealarm.com. Цели: открытый API NEPTUN `https://neptun.in.ua/api/v1/threats`, без ключа. Сервер обновляет и кеширует данные раз в 10 секунд; WebSocket не используется.
- Красный уровень приоритетнее жёлтого, оба видны в деталях. Областная тревога наследуется, локальные тревоги громад отображаются отдельно.
- Оригинальный SVG без круга поворачивается по `heading`: 0° север, 90° восток. Если курс отсутствует, сохраняется исходное положение значка, а текст сообщает, что курс не указан. Неизвестная классификация не объявляется шахедом по одному стандартному значку.
- Координаты NEPTUN фильтруются полигоном Сумской области. Сообщения `areaOnly` для Сумской области показываются в списке без точечного маркера и курса. Карточки содержат описание, размер группы, достоверность, число источников, время обновления, скорость и погрешность позиции при наличии. Позиции приблизные, данные могут задерживаться. При истечении TTL/ошибках цели скрываются, недоступные тревоги не обозначаются отбоем. Отсутствие отметок не означает безопасность.
- ResizeObserver подстраивает область при изменении контейнера/iframe и переключении панелей. При каждой загрузке панели скрыты, атрибуция OpenStreetMap сохраняется.

Сервер отдаёт только `public/` и `/api/state`. APK, токены, исследовательские файлы и логи не входят в репозиторий или образ. Контейнер работает от UID 65532 с read-only filesystem.
